# Shape Legion (도형 군단) — 설계 문서

독창적인 싱글플레이 도형 군단 자동전투 게임. 장르(진형을 그리고 FIGHT를 누르면 수천 명이 자동으로 싸운다)에서만 영감을 받았고, 이름·도형·규칙·그래픽은 모두 자체 설계입니다.

## 1. 핵심 루프
1. **배치 단계**: 왼쪽 절반(아군 구역)에 격자 브러시로 유닛을 칠한다. 예산 = 골드/인구 상한. 지우개, 유닛 종류 선택, 브러시 크기, 실행 취소/전체 지우기. 오른쪽 절반에는 적 진형이 미리 놓여 보인다.
2. **FIGHT**: 시뮬레이션이 자동 진행. 적이 전멸하면 승리(또는 사기 붕괴).
3. **보상**: 패배해도 골드 지급(승리 시 더 많이). 별 1~3개 = 생존 가치 비율(`Sim.stars()`).
4. **업그레이드 화면**: 인구 상한, 유닛별 능력치, 5갈래 기술 트리(보병·수비·궁병·기병·공성) + 지휘. 쓰러진 유닛은 다음 전투에 모두 복귀(영구 손실 없음).

## 2. 유닛 (모양 = 종류, 파랑/빨강 팀)
| 모양 | id | 이름 | 비용 | 역할 |
|---|---|---|---|---|
| 원 | circle | 병사 | 1 | 균형형 근접, 저렴한 물량 |
| 사각 | square | 방패수 | 3 | 느리고 단단함(방어 0.4). 기수 돌격 피해 감소, 궁수 화살에 약함 |
| 삼각 | archer | 궁수 | 3 | 원거리·고화력·연약. 방패수에 강하고 기수에 약함 |
| 마름모 | rider | 기수 | 4 | 빠름. 첫 타격 돌격 보너스. 궁수에 강하고 방패수에 약함 |
| 오각 | siege | 투석기 | 8 | 초장거리 범위 피해, 느림, 근접 무력(최소 사거리). 뭉친 병사에 강함 |

카운터 구도(대략): 병사→궁수·기수, 방패수→병사·기수·투석기, 궁수→방패수, 기수→궁수, 투석기→병사·궁수·기수.
**모든 수치는 `js/units.js` 한 곳**: `UNITS`(체력·피해·쿨다운·사거리·속도·반경·방어·관통), `MULT[공격자][방어자]`(카운터 배율 표), `PREF`(목표 선호), `CHARGE`(돌격), `HP_SCALE`(전투 길이 전역 조절).

피해 = `dmg × MULT[a][d] × (1 − armor[d]×(1 − pierce[a])) × 돌격보너스`.

## 3. 시뮬레이션 (`js/sim.js`, DOM 없음 → Node/브라우저 모두 실행)
- SoA 타입드 배열(Float32 x,y,px,py,vx,vy,hp,cd / Uint8 type,team,alive,flash / Int32 tgt). 유닛은 풀에서 한 번만 생성, 죽은 유닛은 `alive=0`(인덱스 재사용 없음).
- 고정 30Hz(`DT=1/30`), 렌더는 `px,py → x,y` 보간(60fps).
- 공간 해시: 전체 격자(셀 25, 분리용) + 팀별 격자(셀 50, 목표 탐색용). 매 틱 카운팅 정렬로 재구성.
- 목표: 가장 가까운 적(`PREF` 가중), 유닛마다 임의 위상으로 12틱마다 재탐색, 목표 사망 시 즉시. 주변에 적이 없으면 무작위 적 표본 쪽으로 전진.
- 이동/분리: 속도 보간 + 질량 가중 위치 보정(이웃 푸시는 같은 시작점에서 합산 후 상한 → 처리 순서 편향 없음). 처리 순서는 매 틱 Fisher–Yates 셔플.
- 공격: 근접(즉시), 화살(유도 투사체), 투석(포물선, 착탄 시 범위 피해). 투사체·이벤트는 풀(`PCAP=4000`, `EVCAP=6000`).
- 지형(1e, `js/terrain.js`): 스테이지 데이터 `terrain: { river:{c0,c1,bridges:[[r0,r1]]}, walls:[[c0,r0,c1,r1]], hills:[...] }`(25 단위 거친 격자 64×36) → `sim.setTerrain()`이 `sim.blocked`(비트0 = 물/벽 통행 불가, 비트1 = 벽)를 받음. 이동 시 막힌 칸이면 축별 미끄러짐. 이동 목표까지 직선이 막히면(재탐색 때 `losFlags`로 갱신) 전투 시작 때 한 번 만든 팀별 흐름 지도(적 시작 칸에서의 8방향 경로 거리 → 하강 방향)를 따라 이동. 궁수는 벽이 사이에 있으면 발사하지 않고 돌아가며, 화살은 벽 칸에서 사라짐(강은 통과, 투석 포물선은 벽을 넘음). 언덕 위 궁수·투석기 사거리 ×1.25.
- 결정론: `js/rng.js`(mulberry32) 시드 하나로 전투 전체가 재현됨. 시드는 HUD에 표시, `?seed=N`.
- 전투 종료: 한쪽 전멸. 300초 초과 시 남은 가치로 판정.

## 4. 렌더러 (`js/render.js`, Canvas 2D)
- 스프라이트 아틀라스: 팀×종류×(일반/피격 플래시)×16방향을 줌 구간(1~4배, HiDPI 반영)별로 사전 렌더. 글로우·그림자 포함. `drawImage` 배치 + 뷰포트 컬링.
- 접근성: 파랑 = 실선 외곽선, 빨강 = 점선 외곽선 + 중심 점(색 없이도 구분). `prefers-reduced-motion`이면 화면 흔들림 끔.
- 배경: 격자·팀 구역 색·비네팅을 오프스크린에 1회 렌더(줌 구간 따라 재생성) + 사망 자국 레이어.
- 효과(가산 합성 `lighter`): 사망 파티클, 투사체 궤적, 착탄 링, 저해상도 블룸 패스(1/4 해상도 글로우 점 → 확대 합성). 풀 기반(파티클 7000, 링 300).
- 카메라: 드래그 이동, 휠/핀치 확대(포인터 이벤트 하나로 마우스·터치·펜), 더블클릭/⌖ 화면 맞춤. devicePixelRatio 최대 2.

## 5. 품질/성능
- 총 유닛 상한(품질 메뉴): 500 / 1000 / 2000 / 3000 / **자동**(기본 2000에서 시작, 평균 프레임이 느리면 효과 → 블룸 → 상한 순으로 낮춤, 다음 전투부터 적용). 프리셋이 상한을 넘으면 비율대로 축소하고 안내.
- `📊` FPS/유닛 수/틱 시간 오버레이. `?noadapt=1`로 자동 조절 끄기, `?cap=3000`으로 상한 지정.

## 6. UI/UX
- 한국어 기본, English 선택(`js/i18n.js` 사전; 시작 화면·설정에서 전환, localStorage 저장).
- 모바일/터치 우선: 44px 이상 버튼, 손가락 칠하기·핀치(다음 라운드 칠하기 UI), 일시정지·×1/×2/×4, 같은 시드 다시/새 전투.
- 소리: `js/audio.js` WebAudio 엔진 + `assets/audio/*.ogg`(카탈로그 에셋). 설정에서 전체/효과음/음악 음량·음소거(`localStorage shapelegion.audio.v1`).

## 7. 에셋/라이선스

## 8. 파일 구조(얕게 유지)
`index.html`, `css/style.css`, `js/{main,units,sim,formation,render,ui,i18n,audio,audiotest,rng,selftest,stagetest,stages,deploy,upgrades,skills,terrain,terraintest}.js`, `assets/`, `docs/`, `README.md`, `CREDITS.md`, `LICENSE`.

## 9. 자체 테스트 (`js/selftest.js`)
- 브라우저 `?selftest=1`(`&full=1` 확장), Node `node js/selftest.js [full]`.
- 출력: 600v600 혼성 5시드 승률/전투 시간(90초 미만 확인), 5×5 유닛 상성표(동일 비용, 진영 교대), 1000v1000 틱당 시뮬 ms.

- 지형 검증: `node js/terraintest.js [시드 수]` (지형 안 유닛 0 · 다리 하나짜리 강 600v600이 90초 안에 종료 · 벽 화살 차단 · 1000v1000 평지 vs 강 틱당 ms).
- 스테이지 검증: `node js/stagetest.js [시드 수] [스테이지|all]` (자동 배치 승률 · 병사 덩어리 승률 · 최대 전투 시간), `... 1 1 skills`로 스킬 효과(일제 사격/돌격은 같은 시드에서 3초 뒤 적 체력 비교, 집결은 목표 지점까지 평균 거리).
